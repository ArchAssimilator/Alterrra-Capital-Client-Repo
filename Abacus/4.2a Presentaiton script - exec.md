# Team deck prompt

## Role

You are an executive communications and strategy advisor preparing a slide-deck brief for a senior leadership audience.

## Context

The source analysis has already been completed. It assesses the National Drug and Health Products Authority Bill, 2025, using a Red / Yellow / Green framework:

* **Red** : genuinely new or materially expanded changes with significant cost, process, market-access, or disruption implications
* **Yellow** : changes that require adjustment but are generally manageable and often align with existing good practice
* **Green** : changes that mainly codify what large ethical operators already do, with most of the practical pressure falling on weaker market participants

A first version of the deck was prepared for the board. A second version is now required for the executive team.

This executive-team version should use the  **same underlying content and judgments** , but reorganise the material by **function / sector** rather than by regulatory issue alone.

## Task

Create a slide-deck script for the executive team based on the same Bill analysis, with the content split by function or sector.

The deck should:

* begin with a brief explanation of the Act, the nature of the proposed changes, and why they matter to the business
* include one early slide explaining the Red / Yellow / Green classification system
* then organise the rest of the deck **by function / sector**
* aim for **one slide per function / sector**
* give the clearest emphasis to the **Red** items relevant to that function
* give **less emphasis to Yellow**
* include  **Green only briefly** , ideally as a short note or footnote where space allows

## Instructions

* Keep the audience firmly at executive-team level: practical, commercial, and decision-oriented.
* Use the same substantive conclusions as the prior analysis. Do not change the judgments unless necessary for clarity.
* Structure the deck so each function can quickly see:
  * what is changing for them
  * which Red items matter most
  * the main business and cost implications
* Prioritise clarity and screen economy. Do not overload slides.
* Use concise, board-quality business English.
* Where appropriate, make cost implications explicit even if they cannot be precisely quantified.
* Prefer one slide per function, but combine or adjust only if necessary for clarity and balance.
* Green items should not dominate. They should appear only as a brief reassurance or contextual note where helpful.

## Output

Provide the slide deck in markdown for Gamma.app using this format for each slide:

* `Title:`
* `Subtitle:`
* `Content:`
* `Image prompt:`

Separate slides clearly with `---`.
