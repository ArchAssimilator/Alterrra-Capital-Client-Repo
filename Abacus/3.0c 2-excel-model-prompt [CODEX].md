# Reusable Prompt: Excel Model Generator from HTML Issue Tree With Stateful Logic

---

I am attaching an HTML P&L driver tree. Convert it into a fully working monthly Excel financial model (`.xlsx`) using the exact schema embedded in `const data = {...}` inside the HTML.

This version explicitly supports **stateful monthly logic**, where certain rows in month `n` depend on month `n-1`.

---

### STEP 1 — PARSE THE TREE

Parse the embedded `const data = {...}` object directly.

Required fields:
- `id`
- `label`
- `category`
- `type`
- `op`
- `driver`
- `refOf`
- `formula`
- `note`
- `startingValue`
- `annualGrowth`
- `unit`
- `uncertain`
- `children`
- `timeBehavior`
- `rollForward`

`timeBehavior` meanings:
- `point_in_time`: input-style monthly value from starting value and annual growth
- `same_month_formula`: calculated from same-month child values only
- `stateful_roll_forward`: monthly value depends on prior month plus child-driven components

If the tree lacks `timeBehavior`, fall back:
- input -> `point_in_time`
- calculated -> `same_month_formula`
- ref -> same-column pointer

### STEP 2 — WORKBOOK STRUCTURE

Create two tabs:
- `Assumptions`

Same formatting and indentation conventions as the original prompt:
- `A:G` for depth indentation on `Model`
- `H:AQ` for `Month 1` to `Month 36`

Create two named ranges:

### STEP 5 — MONTHLY FORMULA RULES

For each row in `Model!H:AQ`:

#### Input nodes

If `type: "input"`:

```text
=id * (1 + id_growth) ^ ((COLUMN() - 8) / 12)
```

#### REF nodes

If `type: "ref"`:
- point to the master row in the same month column

Example:

```text
=H12
```

#### Same-month calculated nodes

If `timeBehavior = "same_month_formula"`:
- combine direct child rows within the same month column using child `op`

Example:

```text
=H5*H6-H7
```

#### Stateful roll-forward nodes

If `timeBehavior = "stateful_roll_forward"`:

Month 1:
- if `rollForward.month1Mode = "input"`, use `rollForward.month1Value`
- if `rollForward.month1Mode = "formula"`, construct the formula from the referenced child rows in Month 1

Months 2 to 36:
- use the prior month cell in the same row wherever `components.priorMonth = "prior_month"`
- use the current month child rows for other components

Example patterns:

```text
Month 1: =H10
Month 2+: =H20 + I21 - I22
```

or

```text
Month 1: =H10
Month 2+: =H20 * I21 + I22
```

Interpret `components` as the formula contract.

Supported stateful formulas:
- prior month + additions
- prior month + additions - churn
- prior month * retention + additions
- prior month + inflow - outflow

If a `stateful_roll_forward` node is malformed, flag it in the pre-flight checklist and stop rather than inventing logic.
